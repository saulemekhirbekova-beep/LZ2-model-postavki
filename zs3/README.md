# ЗС 3. Бизнес-кейс, жарғы және жобаның қаржы моделі

## Жоба тақырыбы
Киім сатуға арналған интернет-дүкен (Online Clothing Store).

## Жобаның мақсаты
Шағын киім дүкенінің тауарларын интернет арқылы сатуға мүмкіндік беретін ақпараттық жүйе әзірлеу.

## Жобаның негізгі мүмкіндіктері
- Тауарлар каталогы
- Тауарларды іздеу
- Киім өлшемдері мен түстерін таңдау
- Себет
- Тапсырыс рәсімдеу
- Онлайн төлем
- Әкімші панелі
- Қоймадағы тауарларды басқару
