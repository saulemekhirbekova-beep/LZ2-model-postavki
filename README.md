# Қазақстандағы IT еңбек нарығын зерттеу

## 1. Жоба туралы

Бұл жоба Қазақстандағы IT еңбек нарығын зерттеуге арналған. Зерттеу барысында IT Project Manager мамандығына қойылатын талаптар, қажетті кәсіби және жеке дағдылар қарастырылады.

## 2. Зерттеудің мақсаты

- Қазақстандағы IT Project Manager вакансияларын қарастыру.
- Жұмыс берушілер талап ететін Hard Skills және Soft Skills дағдыларын анықтау.
- Ең жиі кездесетін құралдар мен технологияларды талдау.
- Жеке кәсіби даму жоспарын құру.

## 3. Зерттеу әдісі

Зерттеу үшін hh.kz және LinkedIn платформаларындағы вакансиялар қарастырылды. Вакансиялардағы талаптар кәсіби дағдылар, жеке қасиеттер және жұмыс құралдары бойынша топтастырылды.

## 5. Зерттеу нәтижесі

Зерттеу нәтижесінде IT Project Manager мамандығы үшін коммуникация, жауапкершілік, уақытты басқару, командалық жұмыс, Jira, Agile және Scrum сияқты дағдылардың маңыздылығы қарастырылды.

## 6. Қорытынды

IT Project Manager болу үшін техникалық біліммен қатар, адамдармен жұмыс істеу, жобаны жоспарлау, тәуекелдерді басқару және команданы ұйымдастыру қабілеттері қажет.

## 7. Зерттеу шектеулері

Дағдылар матрицасы мен диаграммадағы пайыздық көрсеткіштер нақты вакансия мәтіндерімен жеке-жеке тексерілгенге дейін алдын ала оқу үлгісі ретінде қарастырылуы керек. Оларды нақты еңбек нарығының статистикасы ретінде ұсынуға болмайды.
