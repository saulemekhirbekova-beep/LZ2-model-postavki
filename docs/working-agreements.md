# Working Agreements

## 1. Басқару ережелері
* Тапсырмалар GitHub Projects тақтасында жүргізіледі.
* Әрбір тапсырма Issue ретінде ресімделеді.

## 2. Атау беру стандарттары (Naming Conventions)
* **Branches:** `feature/issue-id-short-desc`, `fix/issue-id-short-desc`
* **Commits:** `feat: #ID description`, `fix: #ID description`
* **Pull Requests:** `[ID] Title`
* **Issues:** `[TYPE] Description`

## 3. Тапсырма типтері (Issue Types)
* `[STORY]` — Пайдаланушы функционалы
* `[TECH]` — Техникалық тапсырмалар
* `[BUG]` — Қателіктерді түзету
* `[RISK]` — Тәуекелдерді басқару
