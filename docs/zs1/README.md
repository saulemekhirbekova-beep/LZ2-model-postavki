
# ЗС 1. Еңбек нарығын кері инженерия және сәтсіз жобаны талдау

## 1. Жұмыстың мақсаты

IT саласындағы еңбек нарығының талаптарын зерттеу, Project Manager мамандығына қажетті құзыреттерді анықтау және сәтсіз IT жобасының себептерін талдау.

## 2. Жұмыстың міндеттері

1. Қазақстанның IT еңбек нарығынан 10 бос жұмыс орнын зерттеу.
2. Вакансиялардағы талаптар мен құралдарды жинақтау.
3. Қажетті құзыреттердің жиілігін анықтау.
4. Өз құзыреттерімді бағалау.
5. Сәтсіз IT жобасын талдау.
6. Командалық жоба идеясын ұсыну.

## 4. Күтілетін нәтиже

Еңбек нарығына қойылатын талаптарды түсіну, өз білімімдегі жетіспейтін тұстарды анықтау және IT жобаларын басқару бойынша тәжірибелік дағдыларды дамыту.
