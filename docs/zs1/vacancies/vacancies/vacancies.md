## 4. Талдау критерийлері

- **Hard Skills** — кәсіби техникалық дағдылар.
- **Soft Skills** — жеке және коммуникациялық дағдылар.
- **Agile, Scrum, Kanban** — жобаны басқару әдістері.
- **Jira, Trello, MS Project** — жобаны басқару құралдары.
- **Жұмыс тәжірибесі** — жұмыс беруші талап ететін тәжірибе.
- **Білімі** — жұмысқа орналасу үшін қажетті білім деңгейі.

## 5. Күтілетін нәтиже

Зерттеу нәтижесінде Қазақстандағы IT Project Manager мамандығына қойылатын негізгі талаптар анықталады. Жұмыс берушілер жиі талап ететін кәсіби және жеке дағдылар салыстырылады. Алынған мәліметтер болашақ маманның кәсіби даму бағытын анықтауға көмектеседі.
