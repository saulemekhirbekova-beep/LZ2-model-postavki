
# Қазақстандағы IT еңбек нарығын зерттеу

## 1. Зерттеу мақсаты

Қазақстандағы IT Project Manager мамандығына және оған жақын қызметтерге қойылатын жұмыс берушілердің талаптарын зерттеу.

## 2. Зерттеу әдісі

Зерттеу барысында hh.kz және LinkedIn платформаларындағы 10 бос жұмыс орны қарастырылады.

Әр вакансия бойынша компания атауы, қызмет атауы, қала, жұмыс тәжірибесі және жұмыс берушінің талаптары жиналады.

## 4. Талдау критерийлері

- Hard Skills — кәсіби дағдылар.
- Soft Skills — жеке және коммуникациялық дағдылар.
- Agile, Scrum, Kanban — жобаны басқару әдістері.
- Jira, Trello, MS Project — жобаны басқару құралдары.
- Жұмыс тәжірибесі және білімі.
