# Қазақстандағы IT еңбек нарығын зерттеу — қорытынды есеп

## 1. Кіріспе

Бұл зерттеу жұмысы Қазақстандағы IT еңбек нарығын зерттеуге және IT Project Manager мамандығына қойылатын жұмыс берушілердің талаптарын анықтауға арналған.

Зерттеу барысында IT саласындағы бос жұмыс орындары, кәсіби дағдылар және жеке қасиеттер қарастырылды.

## 2. Зерттеу мақсаты

- Қазақстандағы IT еңбек нарығын зерттеу.
- IT Project Manager мамандығына қойылатын талаптарды анықтау.
- Hard Skills және Soft Skills дағдыларын салыстыру.
- Жұмыс берушілердің тәжірибеге қойылатын талаптарын қарастыру.
- Кәсіби даму жоспарын дайындау.

## 3. Зерттеу әдістері

Зерттеу барысында мына әдістер қолданылды:

1. hh.kz платформасындағы бос жұмыс орындарын қарастыру.
2. LinkedIn платформасындағы вакансияларды зерттеу.
3. Вакансия талаптарын салыстыру.
4. Hard Skills және Soft Skills матрицасын құру.
5. Дағдылар жиілігін пайыздық көрсеткішпен бағалау.
6. Диаграммалар арқылы нәтижелерді көрсету.

## 4. Зерттеу нәтижелері

Зерттеу жұмысы аясында 10 IT вакансиясына арналған бастапқы тізім дайындалды.

Негізгі зерттеу бағыттары:

- Компаниялар мен қызмет атауларын салыстыру.
- Жұмыс тәжірибесін зерттеу.
- Кәсіби дағдыларды анықтау.
- Коммуникациялық және басқарушылық қабілеттерді бағалау.
- IT жобаларды басқару құралдарын қарастыру.

## 5. Негізгі кәсіби дағдылар

IT Project Manager маманына қажетті негізгі кәсіби дағдылар:

- Jira;
- Agile;
- Scrum;
- Kanban;
- Confluence;
- SQL;
- MS Project;
- BPMN;
- UML.

## 6. Негізгі жеке дағдылар

- Коммуникация.
- Көшбасшылық.
- Жауапкершілік.
- Уақытты басқару.
- Командамен жұмыс.
- Мәселелерді шешу.
- Стресске төзімділік.
- Сыни ойлау.

## 7. Кәсіби даму жоспары

Зерттеу нәтижелеріне сүйене отырып, үш айлық кәсіби даму жоспары дайындалды.

Бірінші айда Agile, Scrum және Jira меңгеру жоспарланды.

Екінші айда SQL және Confluence бойынша білімді жетілдіру қарастырылды.

Үшінші айда шағын IT жобаны ұйымдастыру және практикалық тәжірибе жинау жоспарланды.

## 8. Қорытынды

Зерттеу нәтижесінде IT Project Manager мамандығы техникалық білімді, басқарушылық қабілетті және тиімді коммуникацияны қажет ететіні анықталды.

Бұл мамандықта кәсіби біліммен қатар командамен жұмыс істеу, уақытты басқару және жауапкершілік маңызды рөл атқарады.

Зерттеу жұмысы Қазақстандағы IT еңбек нарығының талаптарын түсінуге және болашақ кәсіби даму бағытын анықтауға мүмкіндік береді.

## 9. Зерттеу шектеулері

Бұл құжат — бастапқы қорытынды есеп. Вакансиялар тізіміндегі әр хабарландырудың жеке сілтемесі мен талаптары тексерілуі қажет. Дағдылар матрицасы мен диаграммадағы пайыздар нақты вакансия мәтіндері бойынша қайта есептелгеннен кейін ғана түпкілікті статистика ретінде пайдаланылуы тиіс.
